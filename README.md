# Superbadge-1: Prompt Builder Templates — Project 1 (Translate Survey Input)

This folder contains text-only, GitHub-friendly instructions and specs to implement the first project:
- A Flex prompt template that translates Fitness survey input into English (≤255 chars).
- A record-triggered flow that calls the template and writes the translation back to the Fitness record.
- Sample data setup for validation (Latisha Bryce).

Structure:
- prompts/translate-survey-input-flex-template.txt
- flows/translate-fitness-survey-input-flow.txt
- data-setup/latisha-bryce-fitness-record.txt
- validation/checklist.txt

Follow the files in order: prompts → flows → data-setup → validation.
